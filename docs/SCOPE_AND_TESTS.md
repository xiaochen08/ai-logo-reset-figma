# 公开提取边界与验证清单

## 可以发布的内容

- 现有重置版 Vue 页面与组件（42 个）
- 供 UI 理解使用的共享数据结构、画布几何与前端状态
- 本地生成的纯演示 SVG 与 Mock API
- 用于安装、构建、设计交接的文件

## 排除的内容

- 私有仓库历史、部署配置、账户数据、密钥、真实授权信息
- Electron Main、生产 IPC 后端、文件系统权限、存储路径
- 私有照片、客户素材及模型/Worker 二进制资源
- Python 图像合成代码、收费授权、服务器与业务后台

## 演示行为

项目、照片、公共 LOGO、预设、导出进度由 `src/mock/mockBackend.ts` 模拟。
- 项目及演示照片的设置可保存在当前浏览器本地存储（受浏览器限制）。
- 用户临时导入的照片保存在当前页面的 Blob URL；刷新页面后临时照片不保留。
- UI 可模拟人脸识别结果，绝无真实 AI 推理。
- 点击导出仅演示进度和状态，不产生处理后的照片、不扣费。
- Logo 导入可预览，合成与色彩/ICC/EXIF 保真需返回正式桌面端验证。
- 演示 SVG 照片由代码生成，避免公开用户原片。
